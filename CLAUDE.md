## Repository Purpose

This is an educational knowledge repository focused on data engineering and database systems. It contains comprehensive study notes and reference materials in Markdown format.

## Structure

- `docs/Data-engineering.md` — Notes from the DeepLearning.AI Data Engineering Professional Certificate (based on "Fundamentals of Data Engineering" by Reis & Housley). Covers the data engineering lifecycle, AWS services, ingestion/storage/transformation patterns, orchestration with Airflow, and data modeling.
- `docs/Intro-to-Database-Systems-CMU.md` — Notes from CMU 15-445/645 Introduction to Database Systems (Fall 2025, Andy Pavlo). Covers relational model, storage, indexing, query optimization, transactions, concurrency control, and recovery.

## Working with This Repository

- No build system, tests, or CI/CD — this is pure documentation
- Content is written in Markdown with hierarchical heading structure following course/lecture organization
- When adding or editing notes, maintain the existing formatting conventions: hierarchical headings, bullet points for concepts, and inline code for technical terms
